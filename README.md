## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/dhanushgowda1706-beep/ML-LAB-2026-27-5TH-SEM-.git
```

### 2. Navigate to the Project Directory

```bash
cd ML-LAB-2026-27-5TH-SEM-
```

### 3. Install Required Libraries

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Alternatively, notebooks can be opened and executed using Google Colab.
